# CHED_HEIs_RegionIII
A simple exploratory analysis project done on MySQL. Here, I used queries to analyze data from CHED about Higher Educational Institutions (HEIs) in Region III of the Philippines. 
Original CSV file can be downloaded from the CHED website (https://legacy.ched.gov.ph/list-of-higher-education-institutions-2/). The data I used for this project was from October 2025.

Check out the two SQL files I uploaded for the queries!
