# CHED_HEIs_RegionIII
A simple exploratory analysis project done on MySQL. Here, I used queries to analyze data from CHED about Higher Educational Institutions (HEIs) in Region III of the Philippines. 
Original CSV file can be downloaded from the CHED website (https://legacy.ched.gov.ph/list-of-higher-education-institutions-2/). The data I used for this project was from October 2025.

Check out the two SQL files I uploaded for the queries!

You can also see my Tableau dashboard for this project at: https://public.tableau.com/views/HEIsinRegionIIICentralLuzon-CHEDData/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link.


### Important Terms
- Commission on Higher Education (CHED): the governing agency body for Higher Educational Institutions (HEIs) in The Philippines.
- HEIs: educational institutions in The Philippines that provide tertiary education.
- State Universities and Colleges (SUCs): HEIs funded by the national government.
- Local Universities and Colleges (LUCs): HEIs funded by Local Government Units (LGUs).
- Private: HEIs funded and managed by private institions, organizations, or corporations.
- Municipality: a type of LGU in The Philippines (for more information refer to Title II of the Local Government Code of 1991).
- City: another type of LGU that is higher in political/administrative status than a municipality (refer to Title III of the Local Government Code of 1991).
